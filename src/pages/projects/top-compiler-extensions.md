## Overview

For my Fall 2026 Compilers class, I was expected to extend a compiler for TOP, to include several new featurse, and had to work through it via careful planning and close knowledge of the compilation pipeline! It was split into several stages, with the first being parsing, but eventually we made it all the way to code generation, allowing us to run our programs using newly added for loops, sequences, and lambdas.
