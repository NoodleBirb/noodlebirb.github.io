## Overview

I architected and implemented a ROS 2 state machine and autonomous excavation/dumping systems using asynchronous Actions. The autonomy stack integrates RTAB-Map visual SLAM, Nav2 with A* and Theta* planning, and AprilTag localization, alongside LiDAR/depth-camera point clouds and PyTorch U-Net segmentation. C++ socket telemetry feeds robot state and sensor feedback to a real-time React operator interface. January 2026 – Present.
